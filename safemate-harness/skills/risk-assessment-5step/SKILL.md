# 위험성평가 5단계 프레임워크

근거: 산업안전보건법 §36, KOSHA Guide G-101.

## 5단계

```
1. 사전 준비  →  2. 유해위험요인 파악  →  3. 위험성 추정  →  4. 위험성 결정  →  5. 위험성 감소 조치
```

## 단계별 가이드

### 1. 사전 준비
- 대상 작업·공정·장소 정의
- 작업 인원 구성 (정규/협력사/외국인 비율, 신규자 여부)
- 기상 조건 (옥외 작업 시)
- 사용 장비·도구 목록
- 작업 시간대 (주간/야간/교대)

### 2. 유해위험요인 파악 (Hazard Identification)
**6 카테고리** (KOSHA 분류):
- 기계적 (협착·전도·낙하·충돌)
- 전기적 (감전·정전기·아크)
- 화학적 (흡입·접촉·인화)
- 생물학적 (감염·알레르겐)
- 인간공학적 (근골격계·반복동작·중량물)
- 사회심리적 (스트레스·교대 피로·언어장벽)

### 3. 위험성 추정 (Risk Estimation)
**위험성 = 가능성(빈도) × 중대성(피해)**

| 가능성 | 매우높음(5) | 높음(4) | 보통(3) | 낮음(2) | 매우낮음(1) |
| 중대성 | 사망(5) | 중상(4) | 경상(3) | 응급(2) | 없음(1) |

위험성 점수 = 가능성 × 중대성 (1~25)

### 4. 위험성 결정 (Risk Evaluation)
| 점수 | 등급 | 대응 |
|---|---|---|
| 1~6 | 낮음 | 현 수준 유지·모니터링 |
| 7~12 | 보통 | 합리적 감소 조치 |
| 13~18 | 높음 | 즉시 감소 조치 + 작업 검토 |
| 19~25 | 매우높음 | 작업 중단·재설계 |

### 5. 위험성 감소 조치 (Risk Control)
**통제 위계 (Hierarchy of Controls)** — 위에서 아래로:
1. 제거 (Elimination) — 위험 자체 제거
2. 대체 (Substitution) — 덜 위험한 대안으로 교체
3. 공학적 통제 (Engineering) — 가드·인터록·격리
4. 관리적 통제 (Administrative) — SOP·교육·교대
5. PPE (개인보호구) — 마지막 수단

→ 카탈로그 JSON의 `mitigations` 는 가급적 3~5번 중 위쪽 (공학·관리)을 우선 채우고, PPE 는 별도 `ppe` 필드.

## 시나리오 다양성 체크 (카탈로그 작성 시)

work_type 별 baseline 마다 시나리오 작성 시 다음을 균형있게 포함:
- ☑ 통상 작업 중 사고
- ☑ 외국인 작업자 / 신규자 SOP 미숙지
- ☑ 기상 변화 (옥외) 또는 환기 실패 (밀폐)
- ☑ 인접 작업·혼재작업 영향
- ☑ 야간·교대 피로

## 출력

- baseline 별 5단계 점검 결과
- 누락된 위험요인 카테고리
- 감소 조치 통제 위계 분포 (1~5번 중 어디에 치우쳤는가)
- 시나리오 다양성 체크 결과
