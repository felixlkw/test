# 안전 법령·기준 인용 표준

## 인용 출처 우선순위

1. **산업안전보건법** (법률) — 사업주 의무, 처벌 조항
2. **산업안전보건기준규칙** (고용노동부령) — 구체 안전 기준 (가장 자주 인용)
3. **중대재해처벌법** (법률) — 경영책임자 의무
4. **KOSHA Guide / Code** — 권장 절차 (법적 강제 아님, 베스트프랙티스)
5. **KEC (한국전기설비규정)** — 전기 안전
6. **국제 표준** — IEC, IEEE, ISO (한국 표준 부재 시 보완)

## 표준 인용 형식

```
산업안전보건기준규칙 §<조문번호> (<키워드>)
```

예시:
- `산업안전보건기준규칙 §42, §43 (안전대·작업발판)`
- `산업안전보건기준규칙 §618~625 (밀폐공간)`
- `산업안전보건법 §36 (위험성평가)`
- `중대재해처벌법 §4 (사업주 의무)`
- `KOSHA Guide P-110 (작업허가서)`
- `한국전기설비규정 §232.5 (가공전선 이격거리)`

## 검증 절차

1. 조문 번호 인용 전 web search 또는 KOSHA 법령 DB 확인 (개정 빈번).
2. 키워드가 조문 제목과 일치하는지 확인.
3. 조문 범위(`§A~B`)는 실제 연속된 조문 묶음만 사용.

## 금지 사항

- 출처 없는 안전 권고 — 회피, 또는 "베스트프랙티스" 명시.
- 조문 번호 추측 — 모르면 web search 또는 "조문 번호 확인 필요" 표시.
- 한국 법령에 없는 내용을 한국 법령으로 인용 — IEEE/IEC 등 별도 표시.
- `§` 기호 대신 "제42조" 같은 한자식 표현 혼용 — `§` 로 통일.

## 카탈로그 JSON 인용 위치

```json
{
  "id": "CRF-01",
  "content": "...",
  "regulation": "산업안전보건기준규칙 §42, §43 (안전대·작업발판)",
  ...
}
```

`regulation` 필드는 한국어 표기. 영어 번역(`regulation_en`)은 현재 스키마에 없음.

## 출력

- 인용된 조문·가이드 목록.
- 출처 미검증 항목 표시 (critic 후속 검수 권장).
